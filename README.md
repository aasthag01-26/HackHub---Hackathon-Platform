# HackHub – Hackathon Platform

HackHub is a collaborative platform designed to help students manage hackathon projects, coordinate with teammates, organize tasks, and improve productivity.

## Features
- User Authentication
- Team Creation and Management
- Team Member Collaboration
- Task Management
- Project Deadline Tracking
- AI-powered Pitch Generation
- File Management
- AI-powered Text Summarization

## Tech Stack
- Frontend: Next.js, React, TypeScript, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB
- AI Integration: Google Gemini API
- Additional Tools: Python, Flask

## Installation and Setup

1. Clone the repository:
   `git clone YOUR_REPOSITORY_URL`

2. Navigate to the project folder:
   `cd intern-project-igdtuw-main`

3. Install dependencies:
   `npm install`

4. Configure environment variables in the backend `.env` file.

5. Start the backend and frontend servers in separate terminals.

## Environment Variables

Configure the required environment variables:

- `PORT`
- `MONGO_URI`
- `JWT_SECRET`
- `GEMINI_API_KEY`

Never upload your `.env` file or expose API keys publicly.

## Contributing

We welcome contributions from developers of all experience levels, especially beginners participating in Open Source Week!

### How to Contribute

1. Explore the [open issues](../../issues) and select a task that matches your skills.
2. Comment on the issue to express your interest before starting work.
3. Fork this repository.
4. Clone your fork:

   ```bash
   git clone YOUR_FORK_URL
   ```

5. Create a new branch:

   ```bash
   git checkout -b feature/your-feature-name
   ```

6. Make your changes and test them.
7. Commit and push your changes:

   ```bash
   git add .
   git commit -m "Describe your changes"
   git push origin feature/your-feature-name
   ```

8. Open a Pull Request against the original repository and mention the related issue.

### Guidelines

- Follow the existing code structure and coding style.
- Keep your commits meaningful.
- Do not commit `.env` files, API keys, or passwords.
- Ask questions in the project discussion channel if you need help.
- Be respectful and collaborative.

Happy Contributing! 🚀
